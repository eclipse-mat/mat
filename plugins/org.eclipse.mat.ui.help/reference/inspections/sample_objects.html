Sample Objects

Selects a subset of objects.

Motivation

Select a subset of objects based on some algorithm.

Arguments

Argument Description
objects An arbitrary set of objects as input.
-number The maximum number of objects to select. If the number of input objects is less than this, then all input objects are selected in the order in which they came (i.e. the -sample algorithm is ignored).
-sample The sampling algorithm to use: FIRST, LAST, RANDOM, LARGEST_RETAINED, LARGEST_SHALLOW, SMALLEST_RETAINED, SMALLEST_SHALLOW.

Result
